PARSING => Parsing is done by browser.Browser convert our code into that format(type) that machine can understand our code.
TOKENIZATION => before parsing,our browser break our code into very small parts that part of code is known as token and that process of converting code into very samll part call Tokenization.
DOM TREE => browser convert our HTMl structure into tree format(like branches of tree) so we call that tree DOM tree.
CSSOM TREE => Browser also convert our CSS into tree structure that structure call CSSOM tree.
RENDER TREE => Browser combine both CSSOM tree and DOM tree called Render tree.
EVENT BUBBLING => When event happen on child it moves upward called event bubbling.
EVENT CAPTURING => When event happen and it goes downward.
EVENT DELEGATION => Instead of adding event listener to all one by one we can perform event delegation like we add event listener to parent and target their child without adding multiple event listeners.
